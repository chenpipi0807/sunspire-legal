向阳之塔 隐私政策

应用名称：向阳之塔（含《向阳之塔：堆叠之旅》）
开发者：陈平安（TapTap 开发者 ID 538035）
生效日期：2026-11-25

一、我们收集哪些信息

本游戏不收集、不上传任何个人信息。

  • 没有账号系统，不需要登录、手机号或实名信息（如平台合规认证要求，由 TapTap SDK 在启动时完成，数据由平台处理）；
  • 不申请通讯录、位置、相机、麦克风、相册等权限；
  • 不接入统计、推送或第三方数据 SDK；如后续接入广告，仅在展示广告时由广告 SDK 处理必要的设备与网络信息，用于广告投放与反作弊；
  • 游戏运行所需的全部资源（语言、图标、画面）都打包在安装包内，离线可玩。

二、本地保存的数据

游戏只在本机保存一项数据：你的最高分（sunspire.best.v1，存在应用私有存储里）。它不会被上传，卸载应用即随之删除。

三、权限说明

  • 网络权限：用于平台合规认证与（如接入时）广告加载；游戏本体不联网也能玩；
  • 保持屏幕常亮：游玩期间不自动息屏，退出游戏即恢复系统默认行为；
  • 无其他敏感权限。

四、未成年人保护

游戏不含内购、社交与用户生成内容。未成年人保护与防沉迷由 TapTap 合规认证统一提供，游戏按平台返回的时段与时长限制执行。

五、数据共享与跨境传输

除上述平台合规认证与广告服务外，我们不向任何第三方提供、转让或公开你的数据。

六、政策更新

如果后续版本加入账号、排行榜或更多广告能力，我们会先更新本政策并在应用内说明。

七、联系我们

如对本政策有疑问，可通过 TapTap 开发者主页（陈平安 / 538035）联系我们。
